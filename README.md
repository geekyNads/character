# Site Name

An open-source, visual guide to how firearms work: the cycle of fire, the cartridge, the main action types, a short history of ignition, and the four universal safety rules.

Educational content only. It does not cover building, modifying or acquiring firearms.

## Run it

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Built with Next.js, GSAP and Lenis. Animations switch off when the visitor prefers reduced motion.

## Placeholders to replace

- `lib/site.ts`: site name, repository URL and contact email
- `LICENSE`: copyright holder
- Every image is a labelled placeholder (`Ph` in `app/page.tsx`). Swap each one for a diagram or illustration you have the rights to use.
